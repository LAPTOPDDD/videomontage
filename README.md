# ВИДЕОМОНТАЖ

Лаборатория автоматического видеомонтажа на Python: слайд-шоу из фото под музыку с синхронизацией по битам (librosa + MoviePy), цветомузыка, бас-пульс, эквалайзер-визуализатор, описания фото нейросетью (Ollama). В репозиторий выгружен только **код** — фото, видео и музыка не публикуются.

## 🎯 Суть системы на словах

1. **Монтаж по битам — финальная версия.** `делвет-видео-5-финал-рябочая-с-зумом.py` (корень) и её предшественники в `Новая папка (3)/`:
   - скрипт сам находит все `.jpg/.png` и первый `.mp3/.wav` в текущей папке;
   - `librosa` считает темп и кадры ударов (`beat_track`), фото меняются каждые `BEATS_STEP` удара (по умолчанию 2);
   - каждое фото масштабируется «на весь экран» под вертикаль 1080×1920 (9:16) с кадрированием по центру;
   - эффект плавного наезда (zoom, `ZOOM_SPEED=0.1`) — «рябь»/зум;
   - музыка зацикливается (`vfx.loop`), если короче видео; рендер `STYLISH_REELS.mp4` (libx264 + aac, 30 fps), явное закрытие ресурсов против WinError 6.

2. **Эволюция скриптов** (по версиям, от простого к сложному):
   - `111.py`, `222.py` — базовый монтаж по битам (смена фото каждые N ударов, `BEATS_STEP=16`);
   - `делвет-видео-1.py` — AI-подписи: vision-модель `moondream` описывает фото, `llama3:8b` переводит и стилизует заголовок, текст на клип через `TextClip`;
   - `делвет-видео-2.py` — ускоренная версия на одной модели `llava` (2–3 слова на русском);
   - `делвет-видео-3.py` — горизонталь 1920×1080, `делвет-видео-4.py` — вертикаль 1080×1920;
   - `делвет-видео-5-финал-яркость-контраст.py` — + ручная цветокоррекция (яркость/контраст через numpy);
   - `...-перено-на-след-песню.py` — обработка нескольких mp3: по одному видео на каждую песню;
   - `...-перено-на-след-песню-разную.py` — то же, но с разными настройками цветокоррекции на каждом ролике (`BRIGHTNESS`, `CONTRAST`).

3. **Визуальные эффекты.**
   - `цветомузыка.py` — STFT-разложение аудио на три полосы: бас → красный, середина → зелёный, верх → синий; нормализация с усилением вспышек (`power=1.5`), кадр RGB пересчитывается на каждой секунде;
   - `бас-вибро.py` — «пульс» размера фото от баса: `pulse = 1 + 0.05 * sin(π·t/dur)`, рендер `pulse_video.mp4`;
   - `виз-стобики.py` — эквалайзер из 30 столбиков (мел-спектрограмма librosa) поверх фото, рисуется в `make_frame`;
   - `вижу-фото.py` — минимальный пример: Ollama `moondream` выдаёт подпись 3–5 слов для каждого фото (подпись для будущего видео).

4. **Запуск.** Все скрипты — «положи фото и mp3 в папку, запусти». Ничего конфигурировать не нужно: пути берутся из `os.listdir('.')`.

## 📁 Структура папок

| Путь | Назначение |
|------|------------|
| `делвет-видео-5-финал-рябочая-с-зумом.py` | финальная версия: биты + зум + вертикаль 9:16 + зацикливание музыки |
| `Новая папка (3)/111.py`, `222.py` | базовые версии монтажа по битам |
| `Новая папка (3)/делвет-видео-1.py`, `-2.py` | AI-подписи фото (moondream + llama3:8b / llava) |
| `Новая папка (3)/делвет-видео-3.py`, `-4.py` | горизонтальный и вертикальный форматы |
| `Новая папка (3)/делвет-видео-5-*.py` | цветокоррекция, несколько песен, разные настройки |
| `Новая папка (3)/цветомузыка.py` | RGB-цветомузыка по частотным полосам |
| `Новая папка (3)/бас-вибро.py` | пульсация размера от баса |
| `Новая папка (3)/виз-стобики.py` | столбики эквалайзера поверх фото |
| `Новая папка (3)/вижу-фото.py` | подписи фото через Ollama |

## 🚀 Запуск

```bash
pip install librosa moviepy numpy ollama
# (для AI-подписей) ollama pull moondream && ollama pull llama3:8b или llava

cd папка_с_фото_и_mp3
python "делвет-видео-5-финал-рябочая-с-зумом.py"
```

Выход: `STYLISH_REELS.mp4` (или `pulse_video.mp4` у `бас-вибро.py`).
